# TERRA / EOS

Mobile-first 3D alien-planet factory automation and terraforming prototype.

## Initial vertical slice

- Three.js WebGL, voxel ore node and mechanical rotary drill
- Straight, one-block incline, 90-degree right turn, final straight conveyor
- Ore items emitted from the drill and transported continuously
- Touch orbit, zoom, pause, speed, and manual pickup

Open `index.html` via a local HTTP server (for example `python -m http.server 8080`). Three.js is loaded via CDN, so network access is required.

GitHub Actions are not configured or run.
