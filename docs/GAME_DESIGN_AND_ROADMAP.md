# TERRA / EOS — 확정 게임 설계 및 구현 로드맵

> 기준일: 2026-11-14 · 상태: **설계 합의 사항 기록**. 이 문서는 모든 기능이 구현됐다는 뜻이 아니다.
> 게임: **TERRA** / 현재 개발 저장소: **EOS**.
> **구현 여부는 이 문서의 구현 현황과 실제 소스·테스트를 대조한다.** 계획을 실행 사실로 표현하지 않는다.

## 1. 개발 방향과 범위

- Roblox **Islands**류의 **3D 복셀 스카이랜드 + 채집·가공·공장 자동화 + 탐험·전투**를 결합한 게임.
- **싱글플레이 전용**. 개발자가 운영하는 중앙 서버에 플레이어마다 독립적인 섬과 월드를 저장한다.
- **멀티플레이, 플레이어 직접 서버 개설, 타인 섬 방문·거래**는 초기 개발 범위에서 제외한다.
- 모바일·태블릿 조작을 우선 지원하며, 데스크톱 키보드·마우스도 지원한다.
- 현재 Node.js + Three.js 프로토타입은 게스트 쿠키 기반이다. 정식 서버·계정·클라우드 운영과는 구분한다.

## 2. 세계 단위·시작 섬·캐릭터 [확정]

- **복셀 블록 한 변 1m**. 이동·충돌·배치·거리 등 게임 좌표계를 미터 기준으로 통일한다.
- 플레이어 **키 약 1.78m**, 평범한 인체 비례. 블록 대비 캐릭터를 임의로 축소·확대하지 않는다.
- 시작 섬: **16×16칸**, **총 두께 3칸**, 윗면이 평평한 잔디, 그 아래는 **흙만**.
- 시작 섬 지하에 **돌층·자연 동굴·지하 광산을 만들지 않는다**. 돌을 포함한 광물은 별도 **광맥 노드** 자원이다.
- 시작 섬에는 나무 2그루. 섬의 블록을 설치·제거하며 건축 영역 확장.
- 기본 섬은 사전에 정한 형태로 시작. 이동 중 낭떠러지 추락 시 피해를 주고 **시작 지점(왼쪽 기준)**으로 복귀하도록 설계한다. 현재 프로토타입의 추락 리스폰과 피해·위치 규칙은 별도 완성 필요.
- 사이드뷰가 아닌 **3D 3인칭 카메라**, 모바일 조이스틱·시점 회전·점프 지원.
- 플레이어 모션은 걷기 중 **양다리·양팔의 작은 교차 흔들림(마인크래프트 계열)**, 정지 시 자연스럽게 복귀.

## 3. UI·인벤토리·도구 [확정]

- **하단 퀵슬롯 8칸**, 전체 인벤토리 열기/닫기. 장착 도구·블록이 손에 보이도록 한다.
- 도구: **곡괭이 = 돌·광물**, **삽 = 흙·모래**, **도끼 = 나무**. 자원과 도구 종류가 맞아야 채집된다.
- 블록 설치는 **설치 가능한 블록 아이템을 손에 들었을 때만** 가능하다.
- 채굴은 **길게 누르기**. 진행률은 자원/블록 근처에 **게이지로 표시**, **퍼센트 숫자는 표시하지 않는다**.
- 직접 채굴·사냥한 아이템은 **지면에 떨어뜨리지 않고 곧바로 인벤토리**로 들어간다. 원거리 처치도 동일.
- 기계가 배출하거나 바닥에 놓인 아이템/컨베이어 위 아이템은 **자동 줍기 금지**: 플레이어가 **직접** 주워야 한다.
- 획득 시 화면 **오른쪽 아래**에 작은 알림 (예: `흙 ×1`). 장황한 HUD 설명은 지양한다.

## 4. 광맥·재생·자원 밸런스 [확정 방향]

- 돌·철·구리 등 자원은 별도 **설치형 광맥 노드**로 취급한다. 흙 지형의 숨겨진 광물층이 아니다.
- 광맥을 **플레이어가 배치·옮겨** 공장/드릴 생산라인을 설계한다.
- 새로운 광맥은 **탐험 섬에서 획득**할 수 있고, 진행에 따라 구매·해금하는 방식도 계획한다. 획득처·가격·제한은 후속 밸런싱 대상.
- 각 광맥은 **현재 매장량 / 최대 매장량 / 회복 누적 시간**을 가진다.
- 채굴하면 **현재 매장량이 줄고 0이 되면 일시적으로 채굴 불가**. **노드는 사라지지 않고 매우 느리게 자동 회복**한다.
- 자연 회복이 느리므로 광맥 다수를 모으고 드릴로 채집하는 것이 생산량 확대의 핵심. 후반에는 회복 촉진 도구/기술도 고려한다.
- 광맥 배치 공간 제한, 광맥 구매 조건·종류별 용량·정확한 회복 속도는 **수치 확정 전**이다.
- 초기에는 생산이 완전히 막히지 않도록 적절한 **초기 매장량**을 제공한다.

## 5. 단일 인게임 시간계 [확정]

- **현실 1분 = 인게임 12분**, 게임 시간 12배 가속.
- **자원 재생·채굴·가공·작물 성장·연료 소비·전력·낮밤 등 모든 시간 계산을 하나의 인게임 시간으로 통일**한다. 현실 시간을 별도 생산 타이머로 쓰지 않는다.
- **플레이어가 접속해 활동 중일 때만** 그 플레이어의 월드 시간이 흐른다.
- 연결 종료·미접속·백그라운드의 비활성 상태에는 월드 진행 **완전 정지**. 재접속할 때 오프라인 경과 시간으로 회복·생산을 소급 처리하지 않는다.
- 서버 권한의 `gameTime` 및 타이머 진행값을 월드와 함께 저장하고, 활성 세션/하트비트 유효기간으로 중단을 판정한다.
- 시간 환산 예: **인게임 12시간 = 실제 접속 1시간**. 다음 숫자는 **예시**이지 확정 레시피가 아니다.
  - 예시 광맥 회복: 돌 1개/인게임 6시간, 철 1개/인게임 12시간.
  - 예시 가공: 철 제련 인게임 4분, 강철 인게임 12분.
  - 예시 작물: 성장 인게임 2시간.
- **현 프로토타입에는 이 통합 시간/오프라인 정지 로직이 아직 없다.** 완성으로 표시하지 않는다.

## 6. 채집·공장·물류 [확정 방향]

- 플레이어 직접 채굴 외에 **드릴**로 광맥을 자동 채굴한다.
- 드릴 성능·소비는 재료/등급과 업그레이드(속도·연비)의 영향을 받는다.
- 설치 방향·높이·드릴과 광맥의 정렬을 중요하게 다룬다.
- **컨베이어**는 직선·회전·상향으로 연결한다. 상향 후 상단 연결, 회전 방향 가독성 등 3D 배치 문제를 해결한다.
- 컨베이어/기계 출력 아이템은 물리적으로 운송하고, 플레이어에게 자동 흡수하지 않는다.
- 자원 흐름: 광물 외에 **식량·농작물·보석·특수 광물** 등 확장.
- 가공 단계: **철 → 강철 → 초강철** 같은 다단계 제조. 기초 자원은 상위 기술에서도 지속 사용.
- 생산·가공은 **느리게**, 대신 기계/건축 레시피의 자원 요구량은 **상대적으로 낮게** 책정한다.
- 가공 비율·시간·전력 비용·드릴 수치·컨베이어 속도는 실제 플레이테스트에서 확정한다.
- 이전 컨베이어 실험물은 `prototypes/mining-conveyor.html`에 보관되어 있으나, 메인 게임의 자동화 시스템으로 통합되지는 않았다.

## 7. 섬 탐험·전투·진행 [확정 방향]

- **시작 섬 → 포탈 제작/해금 → 다른 공중 섬·행성**으로 진행.
- 시작 지역에서 기초 자원을 얻고 다른 지역에서 **특수 자원·광맥·기술 재료**를 획득한다.
- 지상에서 나무·농작물·사냥, 광물 채굴은 노드 중심.
- 전투 적·보스 및 지역별 목표를 도입하여 단순 무한 자동화가 아닌 **탐험과 생산의 상호 강화**를 지향한다.
- 지역 수, 보스 구성/전투 수치, 포탈 제작법, 엔딩 방식, 공식 생산/채굴 레시피는 아직 미확정.

## 9. 구현 우선순위·검증 기준

1. **단일 게임시간 엔진**: 연결 활성 상태에서만 12배, 하트비트 만료 시 중지, 오프라인 소급 없음. 재접속·새로고침·서버 재시작·중복 탭 테스트.
2. **광맥 저장 모델**: 노드의 현재량/최대량/회복 시간·이동·배치·수집. 서버 규칙 검증, 레거시 세이브 마이그레이션 테스트.
3. **채굴·인벤토리 서버 검증**: 채굴 유지시간·도구·거리·보유량·중복 요청·동시 작업 서버 검사. 직접 획득 vs 기계 배출 구분.
4. **드릴 + 컨베이어 연동**: 방향·높이·입출력·커브/상향 연결, 자동 줍기 금지, 갱신·복구 검증.
5. **가공·농사·자원경제**: 전력/연료/제련·상위 소재·성장. 단일 인게임 시간계에서 생산/소비 검증.
6. **탐험·포탈·전투·보스**: 지역별 해금, 자원 반환/월드 복귀 및 저장 검증.
7. **정식 운영 보강**: 계정·영속 DB·백업·보안·모바일 성능·실기기 UX.

### 검증 운영 규칙

- 기능 구현 시 **제작 → 테스트 → 실패 원인 분석 → 실제 수정 → 재테스트**. 실패를 성공으로 기록하지 않는다.
- GitHub 문서와 소스·테스트가 일치하는지 확인. 코드 정적 검사만 통과한 것을 실기기 E2E 검증이라고 부르지 않는다.
- **GitHub Actions는 명시적 승인 없이 실행하지 않는다**.
- 완료되지 않은 업무와 확정되지 않은 수치를 문서에 명시한다.
